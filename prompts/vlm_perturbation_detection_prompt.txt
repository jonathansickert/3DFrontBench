[Input]
Two renders of the same indoor scene:
(a) REFERENCE, with numbered markers on candidate objects
(b) TARGET, in which zero or more of those objects were modified

[Task]
For every numbered object, decide whether it was modified and how.
Classes:
- "removed"     : present in (a), absent in (b)
- "scale"       : same position, different size
- "rotation"    : same position, different orientation
- "translation" : moved to a different position
- "none"        : unchanged

Legend:
{legend}

[Output]
JSON array only. One entry per numbered object, with fields in this order:
- "object_number"
- "object_label"
- "evidence"           : 1-3 sentences describing the object in (a) and in (b)
- "perturbation_type"  : one of ["removed","scale","rotation","translation","none"]
- "confidence"         : 0.0-1.0
